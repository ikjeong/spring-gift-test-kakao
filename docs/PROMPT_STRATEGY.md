# 프롬프트 및 AI 활용 방법

## 워크플로우

```
[1단계] 프로젝트 분석 (AI)
    ↓
[2단계] 사용자 시나리오 도출 (AI + 사람)
    ↓
[3단계] 테스트 대상 선별 (사람)
    ↓
[4단계] Skill 정의 (사람)
    ↓
[5단계] 테스트 코드 작성 (AI + Skill)
    ↓
[6단계] Skill 개선 (AI + 사람)
```

---

## 단계별 설명

### 1단계: 프로젝트 분석

AI에게 프로젝트의 맥락(무엇인가, 왜 분석하는가)과 출력 형식을 제시하여 도메인 모델, API 엔드포인트, 사용자 행동 시나리오를 파악한다.

### 2단계: 시나리오 정제

1차 분석 결과에서 부족한 부분을 후속 프롬프트로 보완한다. 도메인 개념 이해, 테스트 가능 범위 한정 등.

### 3단계: 테스트 대상 선별

API로 노출된 기능 중 검증이 필요한 시나리오를 사람이 선별한다.

### 4단계: Skill 정의

가장 간단한 시나리오를 먼저 AI에게 맡겨 결과를 확인한 뒤, 문제점을 파악하여 Skill 문서를 점진적으로 개선한다.

### 5단계: 테스트 작성

정의된 Skill을 활용하여 AI가 시나리오별 인수 테스트를 작성한다.

### 6단계: Skill 개선

리뷰에서 발견된 문제(검증 전략, 데이터 전략 등)를 Skill에 반영하여 반복 개선한다.
